# OnePDF

A free, client-side PDF editor. View, annotate, organize, convert, OCR, sign, compare, and protect PDFs — entirely in your browser.

## Features

| Workspace | What it does |
|-----------|--------------|
| **Editor** | Highlight, underline, sticky notes, zoom, export |
| **Organize** | Reorder, rotate, delete, merge pages |
| **Convert** | Export pages as PNG/JPEG, extract text |
| **OCR** | Tesseract.js scan recognition + correction |
| **Forms** | Fill interactive PDF form fields |
| **Sign** | Draw or type signatures, place on document |
| **Review** | Draw, stamps, comment threads |
| **Protect** | Redact, watermark, scrub metadata |
| **Compare** | Side-by-side visual + text diff |
| **AI** | Local stats, summary, keyword search |
| **Automation** | Batch presets (export, watermark, etc.) |

## Stack

Next.js 16 · PDF.js · pdf-lib · Tesseract.js · IndexedDB · shadcn/ui

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 and import a PDF.

## Privacy

Documents never leave your device. Clearing browser site data removes stored files.
